# 🌦️ Real-Time Weather App

A dynamic web application that fetches and displays live weather data using a third-party Weather API. Users can search for specific cities or use their current location to get instant weather updates.


## ✨ Features

  * **Search by City:** Get weather details for any city worldwide.
  * **Geolocation Support:** (If implemented) Automatically detects the user's current location to provide local weather.
  * **Live Data:** Displays temperature, humidity, wind speed, and weather conditions (e.g., Sunny, Cloudy, Rain).
  * **Dynamic Icons:** Weather icons change based on the current weather status.
  * **Responsive Design:** Optimized for a seamless experience on mobile and desktop.

## 🛠 Tech Stack

  * **HTML5:** Structure of the application.
  * **CSS3:** Custom styling with a modern, glassmorphism or minimalist UI.
  * **JavaScript (ES6+):** Logic for DOM manipulation and fetching data.
  * **OpenWeatherMap API:** (Or specify the API you used) To retrieve real-time meteorological data.
